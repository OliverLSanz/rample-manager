### Updating

Install this version over the previous one: your Library, Patches and settings
stay. From now on, a small card in the corner of the app announces new
versions a few seconds after you open it. **Skip this version** hides it for
good. The app only asks GitHub and oliverlsanz.com whether there is news; it
sends no personal data, and without internet it shows nothing.

### First launch

The macOS app is not notarized: if macOS blocks it, open **System Settings →
Privacy & Security** and choose **Open Anyway**. The Windows installer is
unsigned: in SmartScreen choose **More info → Run anyway**.
