Rample Preview is now **Rample Manager**: a sample Library and kit builder for
the Squarp Rample, on macOS and Windows.

**Download:** `Rample-Manager-macOS.dmg` (Apple Silicon and Intel, macOS 14+) or
`Rample-Manager-Windows-x64-setup.exe` (Windows 10/11). Visual manual:
https://oliverlsanz.com/RampleManager/manual/

### New in 3.0

- **Library.** Import WAV, AIFF, FLAC and MP3 files or whole folders. Originals
  are kept untouched; name, tag, search, audition and move Samples to a
  recoverable Trash.
- **Patches.** The main window is the open Patch: Kits A0–Z99 in the sidebar,
  four voice cards with ordered Layers, and the 16-step sequencer. Delete with
  Undo, duplicate and move Kits, switch Patches from the top.
- **Add Samples panel.** Browse, hear and add Samples to any Voice; select
  several or drag them onto a voice card.
- **Reversible Sample Edits.** Trim, gain, pitch, EQ, echo and reverb over the
  complete Original, saved for every use or as a new Variant.
- **Import Rample SD.** Bring a card (or a copy of one) into a Patch, including
  STOREd Layer modes and selections.
- **Build to SD.** Write a Patch to a folder or card after reviewing the
  difference, with a verified backup of every replaced file and one-click
  restore.
- **Library backups.** Portable, verified snapshots of the whole Library.

### Upgrading from Rample Preview

Your Library stays where it is and opens automatically. On macOS you can delete
the old **Rample Preview** app after installing; on Windows uninstall it from
Settings → Apps. The app never writes the Rample's `_save` settings.

### First launch

The macOS app is not notarized: if macOS blocks it, open **System Settings →
Privacy & Security** and choose **Open Anyway**. The Windows installer is
unsigned: in SmartScreen choose **More info → Run anyway**.
