---
name: release
description: Publish a new Rample Manager version (GitHub Release with Mac and Windows installers), update the website, or send a message to users through the app's startup notice (site/messages.json). Use when Oliver asks to release, ship, tag a version, write patch notes, deploy the website or notify users.
---

Follow `docs/agents/releases.md` in this repository step by step. It covers
choosing and setting the version, writing `docs/releases/v<version>.md` (short
bullets first: the app shows the first five), tagging, watching the Desktop
builds workflow, verifying the published installers and the website, and
editing and deploying `site/messages.json`.
